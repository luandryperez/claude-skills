# claude-skills

Skills personales para [Claude Code](https://claude.com/claude-code).

Para usar uno de estos skills en un proyecto o de forma global, colócalo en
`~/.claude/skills/<nombre>/` (personal) o `.claude/skills/<nombre>/` dentro de un
repo (por proyecto).

## Skills

| Skill | Qué hace |
|---|---|
| `mis-actividades` | Consulta y muestra actividades planificadas asignadas en Odoo, ordenadas por vencimiento. |
| `mi-timesheet-diario` | Genera entradas de timesheet diario orientadas a valor. |
| `redactor` | Transforma una resolución técnica en comunicación profesional para el cliente. |
| `timesheet` | Genera entradas de timesheet a partir de resolución técnica + comunicación al cliente. |
| `odoo-guru` | Referencia de conocimiento interno del ORM y flujos de Odoo. |
| `crear-minuta` | Convierte una transcripción de llamada en una minuta formal como Google Doc. |
| `client-test-instructive` | Genera un instructivo de pruebas UAT interactivo a partir de un MR/PR. |
| `issue-diagnosis-report` | Investiga un posible bug en Odoo y genera un reporte de diagnóstico HTML. |
